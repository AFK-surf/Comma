# Contribute to Comma

Use the development commands in [README.md](README.md).
Follow [AGENTS.md](AGENTS.md) and the instructions for each changed package.
Add tests for changed behavior. Include the test results in your pull request.

## Contributor agreement

Read [CLA.md](CLA.md) before you submit a contribution.
Each contributor must post its acceptance statement on the pull request before merge.
The statement must identify the contributor and any represented entity.
Maintainers check acceptance against the contributors in the pull request.
There is no automated CLA service yet. A checkbox alone does not record acceptance.

The CLA preserves your ownership. It permits AFK AI, Inc. to distribute your contributions under open-source or commercial terms.
